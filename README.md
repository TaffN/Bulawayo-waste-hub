# Bulawayo Waste Hub (prototype)

A clickable demonstration of a ward-level waste reporting and coordination platform for Bulawayo, built to support Karl Malotane's PhD study on a multi-stakeholder framework for sustainable waste management.

**Everything in this demo is invented sample data.** It is not connected to the City Council, EMA or any real system.

## What it shows

- A schematic ward map of Cowdray Park (and a placeholder second ward) with reported dump sites
- Reporting by simulated WhatsApp and USSD (basic phone) in English, isiNdebele and chiShona (local-language wording is a draft awaiting native-speaker review)
- AI triage, duplicate merging and routing to the responsible partner by agreed rules
- Data tables and settings, with indicator baselines waiting for the survey results

## How to run it

Open `index.html` in any web browser. There is nothing to install.
